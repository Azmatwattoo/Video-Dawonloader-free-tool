Frequently Asked Questions

Some basic information about AzDar Downloader.

How do I download a video?

Paste a supported media URL into the input box and press Analyze. Available formats will then appear when the backend is connected.

Is AzDar Downloader free?

The V1 frontend is completely free to use. Hosting and any third-party API costs may depend on the final backend implementation.

Can I use it on my phone?

Yes. The website is responsive and designed for Android, iPhone, tablet and desktop screens.

Does V1 actually download videos?

V1 is the frontend prototype. The actual media extraction and downloading engine will be added through a backend/API in a later version.
